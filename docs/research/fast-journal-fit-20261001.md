## SoftwareX requirements actually read

Original software publication uses the mandatory journal template, maximum4000
words (excluding title/authors/affiliations/references/metadata tables), at most
six figures. Requires an open-source distribution with support material and
publicly accessible GitHub repository, README and license. The guide requests
source in repo/src. Accepted software is archived in the journal GitHub repo.
Our anonymous offline mapping demo is not the full software distribution.
The review is single-anonymized. Data availability statement is required; data
deposit/link or an explanation of unavailable data is required by its Option C.

Authors are finalized at submission. Before acceptance, additions/removal/order
changes require editor approval and written consent from all involved authors;
after acceptance changes including corresponding author are not allowed.
Corresponding author affiliation is used for publishing-agreement eligibility.
No agreement for Zhejiang Sci-Tech University has been established here.

## Recommendation

SoftwareX is the closer match to the current tool contribution if the author
can fund the APC and is willing to prepare a full open-source release. IEEE
Access is a secondary route; rapid review alone is not a reason to expand a
bounded tool description into an unsupported general-effect study.
Neither current manuscript is ready for immediate journal submission. First
perform a local release-readiness audit and shortlist a manuscript outline
against SoftwareX's mandatory template. No public release without authorization.
If an APC around USD1920--2160 is unaffordable, broaden the search to subscription
publication routes before choosing either fully open-access journal.
Do not submit overlapping manuscripts simultaneously to a journal and DSN.
